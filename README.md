
# Стандартная атмосфера по ГОСТ 4401-81

Программная реализация модели стандартной атмосферы по ГОСТ 4401-81 на языке Python.

## Описание проекта

Программа предназначена для расчёта основных параметров стандартной атмосферы в зависимости от геометрической высоты.

Расчёт выполняется в соответствии с математической моделью, представленной в ГОСТ 4401-81.

## Возможности

Программа позволяет определить следующие параметры атмосферы:

- Ускорение свободного падения, м/с²;
- Температуру, К;
- Давление, Па;
- Плотность воздуха, кг/м³;
- Скорость звука, м/с;
- Динамическую вязкость воздуха, Па·с.

## Диапазон расчёта

Расчёт выполняется для геометрических высот от −2000 до 85000 м.

## Использование

Для расчёта параметров стандартной атмосферы необходимо импортировать функцию `atmosphere_geometrical` из модуля `src.atmosphere`.

### Пример

```python
from src.atmosphere import atmosphere_geometrical

# Геометрическая высота, м
h = 10000

# Расчёт параметров атмосферы
g, T, p, rho, a, mu = atmosphere_geometrical(h)

print(f"Ускорение свободного падения: {g:.5f} м/с²")
print(f"Температура: {T:.2f} К")
print(f"Давление: {p:.2f} Па")
print(f"Плотность воздуха: {rho:.6f} кг/м³")
print(f"Скорость звука: {a:.2f} м/с")
print(f"Динамическая вязкость: {mu:.8e} Па·с")
```

Для запуска примера из корневой папки:

```powershell
python -m examples.basic_usage
```

### Возвращаемые значения

Функция `atmosphere_geometrical(h)` возвращает кортеж из шести параметров:

| Параметр | Обозначение | Единица измерения |
|---|---|---|
| Ускорение свободного падения | `g` | м/с² |
| Температура | `T` | К |
| Давление | `p` | Па |
| Плотность воздуха | `rho` | кг/м³ |
| Скорость звука | `a` | м/с |
| Динамическая вязкость | `mu` | Па·с |
